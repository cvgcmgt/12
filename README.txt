GitHub old-site redirect package

এই ফাইলগুলো পুরোনো GitHub Pages URL থেকে নতুন Vercel URL-এ পাঠাবে।

গুরুত্বপূর্ণ:
- robots.txt-এ block দেওয়া হয়নি, যাতে Google পুরোনো URL crawl করে noindex/redirect দেখতে পারে।
- কিছুদিন redirect চালু রাখলে Google নতুন Vercel URL ধরতে সুবিধা পাবে।
- পরে চাইলে GitHub Pages পুরোপুরি unpublish করতে পারবেন।
